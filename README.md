# Personal Expense Tracker

A modern, responsive Personal Expense Tracker web application built with vanilla HTML5, CSS3, and JavaScript.

## Features

- **Expense Logging**: Add transactions with date, description, category, and amount.
- **Real-Time Summary**: Dynamic metrics showing total spend, transaction count, and top expense category.
- **Category Breakdown**: Interactive visual progress bars representing spending distribution.
- **Sorting & Filtering**: Interactive column sorting by Date and Amount.
- **Data Persistence**: Uses browser `localStorage` to save your records across sessions.
- **Netlify Ready**: Configured with `netlify.toml` for static hosting and security headers.

## Tech Stack

- HTML5 (Semantic landmarks & accessible markup)
- Vanilla CSS3 (Custom properties, grid layout, responsive typography)
- Vanilla JavaScript (DOM manipulation, local storage, custom comparator sorting)
